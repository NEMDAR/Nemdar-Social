# حالة التنفيذ v0.5

## منفذ وقابل للاختبار

- تسجيل دخول، انتهاء جلسة بعد 8 ساعات، خروج، تغيير كلمة مرور وإلغاء كل الجلسات.
- كلمات مرور scrypt، cookies HttpOnly/SameSite، تحقق Origin وCSRF، وحد لمحاولات الدخول.
- مستخدمون بأدوار admin/editor/reviewer/viewer مع قائمة عملاء مسموحين؛ التحقق على الخادم.
- SQLite دائمة ومعاملات وrevision لمنع استبدال تعديلات مستخدم آخر.
- عملاء وعلامات متعددة وحسابات متعددة لنفس المنصة، مع منع تكرار الحساب داخل العميل.
- مسودات قابلة للتعديل، مراجعة واعتماد/إرجاع، جدولة وإلغاء بتوقيت دبي/UTC.
- وسائط حتى 10 MB للملف، إرفاقها بالمسودات، وقراءة مع صلاحية العميل.
- تخطيط حملات وميزانية AED واعتماد خطة بدون تشغيل أو دفع.
- BANT وتأهيل الليدز وتحديثها، مؤشرات من بيانات النظام، وسجل نشاط.
- خزنة AES-256-GCM: كتابة وحذف، بيانات وصفية فقط في الواجهة، لا endpoint لاسترجاع السر.
- حزمة نشر Docker/Waitress ونسخ احتياطي متسق.

## غير منفذ — ليس مخفياً وراء أزرار نجاح وهمية

- OAuth التلقائي والإعلانات والتقارير والاستماع والرسائل. النشر للمنصات الأخرى ووسائط فيسبوك غير منفذ.
- موصل نصوص صفحات فيسبوك منفذ، لكنه غير مختبر بحساب حي. لا يُفعّل أي نشر تلقائي؛ يحتاج إعداد صفحة وتوكن وإصدار API ثم إرسالًا يدويًا من المدير.
- مزود توليد AI للفيديو والصور والنص، مع رصيد ومراقبة تكلفة.
- Inbox مستورد من المنصات وإرسال الرسائل وwebhooks.
- تحليلات وصول/إنفاق/إيرادات حقيقية؛ لا يتم توليد أرقام لها.
- تحرير الصور وقص الفيديو، تتبع نسخ الوسائط، وتغيير مواعيد التقويم بالسحب والإفلات.
- تدوير مفتاح الخزنة وانتهاء صلاحية الأسرار وصلاحيات استدعائها للموصلات.
- MFA واستعادة كلمة المرور بالبريد، تقسيم مؤسسات SaaS، وتدقيق أمني مستقل.
- ترحيل بيانات v0.2 من localStorage تلقائياً. البيانات القديمة لا تُحذف؛ يمكن تصديرها من نسختها.

## الاعتمادات اللازمة لإكمال التشغيل الخارجي

- نسخة UAT منشورة؛ أكد المالك إنشاء حساب المدير بنجاح.
- تطبيقات مطورين لكل مزود، Redirect URLs، موافقات الصلاحيات المطلوبة، ثم تسجيل دخول المالك للتفويض. لا تُطلب كلمات مرور السوشيال.
- تحديد أول مزود AI ووضع مفتاحه وحدود الإنفاق في إعدادات الخادم.
- لا يُعد توفر حساب على المنصة إثباتاً لتوفر API للنشر/الإعلانات/الرسائل؛ يراجع كل تكامل على حدة.

## التحقق

39 اختبار خادم وموصل وطابور وإعداد أولي و19 اختبار JavaScript. تحقق الخادم يشمل المصادقة وCSRF والصلاحيات وعزل العملاء والتعارض والوسائط والخزنة ودورة المحتوى وتعطيل المستخدم وتغيير كلمة المرور، إضافة إلى 8 اختبارات خاصة بموصل Facebook. ملفات التصميم الأصلية لم تتغير.

لم يُجر اختبار حي على صفحة Facebook، ولم يُرسل أي محتوى. الاختبارات الخارجية تستبدل Graph API بنقل محلي قابل للتحكم. نُشرت v0.5 أولياً عبر deployment `tqtykekdtwvgdbe3xd7ykqze` بحالة `finished` والتطبيق `running:healthy`؛ أعاد فحص HTTPS النسخة `0.5.0`، وظل `/api/state` يعيد 401 بدون جلسة.

## إضافة v0.4

طابور دائم مستقل لكل حساب، تشغيل آمن لعاملين بالتزامن، منع إعادة إرسال الناجح، وإيقاف النتائج غير المؤكدة للمراجعة. الجدولة تنشئ المهام؛ الإلغاء وإعادة الجدولة لا يكررانها. المواعيد القديمة تُرحّل عند فتح قاعدة البيانات. شاشة متابعة تعرض الحالة والمحاولات ومعرّف استلام الموصل إن توفر. العامل التلقائي لا يسجل موصلات. v0.5 يتيح موصل فيسبوك فقط عبر إجراء إرسال يدوي محدد الهدف.

## التقويم الشهري

عرض شهر وقائمة، التنقل بين الشهور، تحديد يوم وفتح تفاصيل المنشور، مع سجل المنشورات المجدولة والمنشورة والناجحة جزئياً. التجميع حسب يوم دبي بغض النظر عن توقيت المتصفح. 3 اختبارات جديدة لحدود اليوم والسنة والسنة الكبيسة واستبعاد المسودات. لا يغير التقويم مواعيد النشر بالسحب.

## جاهزية العميل

قائمة تجهيز مستقلة لكل عميل، مع روابط مباشرة للخطوات وصفحة ربط تعرض الحسابات لكل منصة. لا يُعد تسجيل الحساب اتصالاً فعلياً. اختباران لعزل العملاء واستبعاد المواعيد الملغاة من الجاهزية.

## v0.5 — موصل صفحات فيسبوك

- تحقق هوية الصفحة عبر Graph API ثم حفظ التوكن AES-GCM مرتبطاً بالعميل والحساب. لا يثبت التحقق صلاحية pages_manage_posts؛ رفض الصلاحية يظهر عند محاولة الإرسال.
- نص فقط؛ يرفض المرفقات بدلاً من إسقاطها. إرسال يدوي للمدير من الطابور بعد الموعد، تأكيد صريح لكل هدف. لا إرسال تلقائي عند الربط، ولا إعادة إرسال للناجح/غير المؤكد.
- إصدار API يُدخل من إعدادات تطبيق Meta ولا يُفترض إصدار افتراضي. انتهاء تفويض محلي خلال سنة يحدده المدير بما لا يتجاوز صلاحية التوكن.
- فصل محلي يحذف التوكن؛ إلغاء التفويض لدى Meta مسؤولية صاحب الحساب. لا OAuth أو تجديد توكن تلقائي حتى الآن.
- تهيئة مفتاح خزنة محلي دائم في بدء الإنتاج إذا كانت الخزنة فارغة؛ لا يُستبدل مفتاح مفقود لبيانات مشفرة موجودة.
- اختبارات النقل ببديل محلي، والتشفير والعزل ورفض المرفقات والتكرار والنتيجة غير المؤكدة. لم يحدث اتصال بصفحة حقيقية أو نشر تجريبي فعلي.
- محاولة قراءة توثيق Meta الرسمي للنشر وPage/feed أعادت HTTP 429؛ لذلك تبقى مطابقة الإصدار والصلاحيات والاختبار الحي متطلب قبول قبل اعتماد الموصل للإنتاج.
