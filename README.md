# NEMDAR Social — v0.8

مساحة عمل عربية RTL لإدارة وكالة سوشيال ميديا، بهوية Stitch المعتمدة. تتضمن الآن خادم بيانات ومصادقة وصلاحيات، وليست مجرد صفحات أو localStorage.

## البداية

Python 3.12+، وNode.js 20+ للاختبارات فقط.

```sh
pip install -r requirements.txt
python -m server.manage init --email YOUR_EMAIL
npm start
```

افتح http://localhost:8080 ثم سجّل دخولك. إعداد المدير تفاعلي، بدون كلمات مرور افتراضية. لا توجد بيانات عملاء تجريبية في قاعدة البيانات الجديدة.

## المتاح

12 قسماً: نظرة عامة، تقييم الشركة، العملاء والحسابات، استوديو المحتوى، مواعيد النشر، متابعة المهام لكل حساب، الليدز، الوسائط، تخطيط الحملات، حالة المنصات، الفريق والخزنة، وسجل النشاط. يدعم عدة علامات وحسابات للعميل، حفظاً دائماً، صلاحيات على الخادم، مراجعة واعتماد المحتوى، حفظ مواعيد UTC وعرض دبي، رفع ملفات وإرفاقها، وتأهيل BANT. يدعم تخطيط واعتماد ميزانية الحملة دون تشغيلها.

تقييم الشركة يبدأ بـSurface Audit من الروابط العامة فقط، مع جامع HTML محدود وآمن ضد SSRF وفصل واضح بين المتاح والمستنتج وغير المعروف. عند التحقق من هوية Facebook أو Instagram يتحول إلى Verified Audit ويضيف أدلة التشغيل الداخلية: دورة المحتوى، موثوقية نتائج النشر، تأهيل الليدز، واعتماد خطط الحملات. يدعم v0.8 مزامنة Insights يدوية للقراءة من Meta وحفظ Snapshot للـ28 يومًا الأخيرة؛ كل metric غير مسموحة تظل «غير متاحة» ولا تتحول إلى صفر.

يتوفر موصل أولي لنشر النص أو صورة JPEG/PNG واحدة على صفحات Facebook، وموصل Instagram Professional لنشر صورة JPEG/PNG واحدة مع Caption. الربط يدوي بواسطة Page Access Token من تطبيق Meta، والتوكن يُشفّر ولا يعود للواجهة. الإرسال يدوي من المدير لكل هدف بعد حلول الموعد، ولا يُعاد إرسال النتيجة الناجحة أو غير المؤكدة. لم تُختبر الموصلات بحساب حي بعد. لا يوجد نشر فيديو أو صور متعددة أو OAuth تلقائي أو تشغيل إعلانات أو رسائل فعلية، وباقي المنصات غير مربوطة.

## الاختبارات

```sh
npm test
```

54 اختبار خادم وموصل وطابور وInsights وجامع عام وإعداد أولي + 28 اختبار JavaScript. الاختبارات تستخدم بديل نقل محلي، ولا تثبت صلاحية تطبيق Meta أو نجاح القراءة/النشر على حساب حقيقي. تفاصيل القيود والتحقق في [حالة التنفيذ](docs/STATUS.md).

## التشغيل على الخادم

[دليل النشر والنسخ الاحتياطي](docs/DEPLOYMENT.md). Dockerfile يستخدم Waitress ومستخدماً غير root وقرصاً دائماً. النسخة مخصصة لوكالة واحدة؛ الصلاحيات تفصل العملاء داخلها. نسخة UAT منشورة على https://social-uat.nemdar.tech.

## تصميم Stitch

`design-preview.html` و`designs/` يحفظان 10 ملفات أصلية دون تعديل، و`screens.json` يسجّل بصماتها. بعض الملفات السبعة الأولى قد تكون أقدم من آخر مراجعة على Stitch؛ نسخ الموبايل المستقلة لم تتوفر للتصدير. التطبيق الجديد يستخدم CSS متجاوباً، ولم يحصل على اختبار بصري بالمتصفح في هذه الجولة.

[المستودع](https://github.com/NEMDAR/Nemdar-Social)

## عامل النشر

`npm run worker` يشغّل عامل المهام على نفس DATABASE_PATH، لكن سجل العامل التلقائي يظل فارغاً عمداً. موصل Facebook يعمل فقط من إجراء المدير الصريح داخل شاشة متابعة النشر، ولا يبدأ نشر تلقائي عند الربط أو تشغيل الحاوية.
