# NEMDAR Social — v0.2

مساحة عمل عربية RTL لإدارة العملاء وحساباتهم والمحتوى والليدز، مبنية على الهوية المعتمدة في Stitch (Cairo، شريط جانبي كحلي، أزرق وتيل).

## التشغيل

المتطلبات: Node.js 20 أو أحدث للاختبارات، وPython 3 لتشغيل خادم المعاينة. لا توجد حزم npm مطلوبة.

```sh
npm start
# افتح http://localhost:8080
npm test
```

## المتاح فعلياً

- ست واجهات مترابطة: نظرة عامة، العملاء والحسابات، استوديو المحتوى، جدول المواعيد، الليدز والتأهيل، سجل النشاط.
- إضافة عميل مع علامة أساسية، وتبديل نطاق العميل في كل الواجهات.
- تسجيل عدة حسابات لنفس المنصة، مع منع تكرار معرّف الحساب لنفس العميل.
- إنشاء مسودة بحسابات محددة ثم مراجعتها واعتمادها وجدولتها محلياً وإلغاء الجدولة.
- تسجيل الليد وتحديث معايير BANT دون اعتبار المعلومات المجهولة موافقة.
- مؤشرات مشتقة من البيانات المحفوظة، بحث وتصفية وسجل تغييرات حسب العميل.
- حفظ localStorage، مزامنة التغييرات بين النوافذ، وتصدير JSON.
- تخطيط متجاوب للموبايل، رسائل أخطاء عربية، نماذج dialog وتسميات حقول.
- التصميم الأصلي متاح على `design-preview.html`. ملفات HTML العشرة الأصلية لم تُعدّل.

## حدود النسخة

هذه نسخة محلية قابلة للتجربة، وليست خدمة إنتاجية منشورة. البيانات تخص هذا المتصفح والجهاز ويمكن فقدها بحذف بيانات الموقع؛ زر التصدير يحفظ نسخة JSON (استيراد النسخ غير منفذ بعد). لا يوجد تسجيل دخول أو عزل أمني على الخادم أو صلاحيات فريق. اعتماد المحتوى هنا إجراء محلي للمستخدم نفسه وليس موافقة مستقلة من العميل. فصل العملاء في الواجهة لا يُعد بديلاً عن العزل الأمني.

الحسابات **غير مربوطة**. لا توجد توكنات أو كلمات مرور مطلوبة أو محفوظة. المواعيد تُدخل وتُعرض بتوقيت دبي وتحفظ UTC؛ لن يتم نشر المحتوى تلقائياً. لا يوجد دفع أو تشغيل حملات أو رسائل فعلية. بيانات البداية عميل افتراضي وحسابان افتراضيان فقط؛ مؤشرات التشغيل تبدأ من البيانات المحلية الحقيقية.

تتوفر علامة أساسية واحدة لكل عميل حالياً. تعدد العلامات داخل العميل، مكتبة الوسائط، الحملات، الرسائل، التحليلات الخارجية وSecret Vault ما زالت في مرحلة التصميم. لا يوجد توليد AI في هذه النسخة.

## التحقق

14 اختباراً تغطي دورة المحتوى، منع تخطي الاعتماد، رفض المواعيد الماضية، فصل نطاق العملاء، تعدد الحسابات ومنع التكرار، تأهيل الليد، حفظ البيانات والتعامل مع التلف. اجتازت ملفات JavaScript فحص الصياغة. لم يتم إجراء اختبار بصري داخل المتصفح في هذه الجولة.

## مصدر التصميم

`designs/` يحتوي 10 ملفات HTML مصدرية و`screens.json` بصمات SHA-256. السبعة الأساسية هي الملفات التي أعادها موصل Stitch وقد لا تمثل أحدث مراجعة ظاهرة في واجهته. الثلاثة الإضافية من استجابة التوليد المحفوظة. نسخ الموبايل المستقلة لم تتوفر للتصدير؛ الواجهة التفاعلية الحالية لها CSS متجاوب خاص بها.

المعاينة الأصلية تعتمد على Tailwind CDN وخطوط وصور خارجية. واجهة التطبيق الحالية تستخدم CSS محلياً وخط Cairo خارجي مع fallback. صور التصاميم وبياناتها أمثلة وليست دليلاً على حقوق استخدام مؤكدة.
