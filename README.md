# NEMDAR Social — v0.5

مساحة عمل عربية RTL لإدارة وكالة سوشيال ميديا، بهوية Stitch المعتمدة. تتضمن الآن خادم بيانات ومصادقة وصلاحيات، وليست مجرد صفحات أو localStorage.

## البداية

Python 3.12+، وNode.js 20+ للاختبارات فقط.

```sh
pip install -r requirements.txt
python -m server.manage init --email YOUR_EMAIL
npm start
```

افتح http://localhost:8080 ثم سجّل دخولك. إعداد المدير تفاعلي، بدون كلمات مرور افتراضية. لا توجد بيانات عملاء تجريبية في قاعدة البيانات الجديدة.

## المتاح

11 قسماً: نظرة عامة، العملاء والحسابات، استوديو المحتوى، مواعيد النشر، متابعة المهام لكل حساب، الليدز، الوسائط، تخطيط الحملات، حالة المنصات، الفريق والخزنة، وسجل النشاط. يدعم عدة علامات وحسابات للعميل، حفظاً دائماً، صلاحيات على الخادم، مراجعة واعتماد المحتوى، حفظ مواعيد UTC وعرض دبي، رفع ملفات وإرفاقها، وتأهيل BANT. يدعم تخطيط واعتماد ميزانية الحملة دون تشغيلها.

يتوفر موصل أولي لنشر **النصوص فقط** على صفحات Facebook. الربط يدوي بواسطة Page Access Token من تطبيق Meta، والتوكن يُشفّر ولا يعود للواجهة. الإرسال يدوي من المدير لكل هدف بعد حلول الموعد، ولا يُعاد إرسال النتيجة الناجحة أو غير المؤكدة. لم يُختبر الموصل بحساب حي بعد. لا يوجد نشر وسائط أو OAuth تلقائي أو تشغيل إعلانات أو رسائل فعلية، وباقي المنصات غير مربوطة.

## الاختبارات

```sh
npm test
```

39 اختبار خادم وموصل وطابور وإعداد أولي + 21 اختبار JavaScript. الاختبارات تستخدم بديل نقل محلي، ولا تثبت صلاحية تطبيق Meta أو نجاح النشر على صفحة حقيقية. تفاصيل القيود والتحقق في [حالة التنفيذ](docs/STATUS.md).

## التشغيل على الخادم

[دليل النشر والنسخ الاحتياطي](docs/DEPLOYMENT.md). Dockerfile يستخدم Waitress ومستخدماً غير root وقرصاً دائماً. النسخة مخصصة لوكالة واحدة؛ الصلاحيات تفصل العملاء داخلها. نسخة UAT منشورة على https://social-uat.nemdar.tech. حالة نشر v0.5 وتحققها تُسجّل بعد اكتمال نشرها.

## تصميم Stitch

`design-preview.html` و`designs/` يحفظان 10 ملفات أصلية دون تعديل، و`screens.json` يسجّل بصماتها. بعض الملفات السبعة الأولى قد تكون أقدم من آخر مراجعة على Stitch؛ نسخ الموبايل المستقلة لم تتوفر للتصدير. التطبيق الجديد يستخدم CSS متجاوباً، ولم يحصل على اختبار بصري بالمتصفح في هذه الجولة.

[المستودع](https://github.com/NEMDAR/Nemdar-Social)

## عامل النشر

`npm run worker` يشغّل عامل المهام على نفس DATABASE_PATH، لكن سجل العامل التلقائي يظل فارغاً عمداً. موصل Facebook يعمل فقط من إجراء المدير الصريح داخل شاشة متابعة النشر، ولا يبدأ نشر تلقائي عند الربط أو تشغيل الحاوية.
